# 工程沙盘虚拟仿真系统（3DBuildingForge）

安徽工业大学 · 建筑工程学院 · 智能建造教学用。把实验室的「工程沙盘」搬到网页上：先认识智慧工地，再看一栋楼从策划、施工、运维到拆除的全过程，最后拆开单个预制构件学安装工艺。

**在线访问：** https://xmm1118.github.io/3DBuildingForge/

> 页面中所有数据均为「教学模拟数据」。

## 四个学习模式
| 模式 | 学什么 | 右侧数据面板 |
|---|---|---|
| ① 智慧工地 | 沙盘上的智慧工地、绿色施工、装配式、安全教育点位；每个点位有讲解和场景演示 | 施工阶段大屏 |
| ② 建造过程 | 时间轴：绿色策划 → 场地准备 → 基坑 → 基础 → 主体结构 → 幕墙装修 → 竣工 → 拆除回收；工序动画，点工序镜头聚焦 | 随阶段变化的施工数据 |
| ③ 建成运维 | 1# 楼分层剖开；能耗、设备、安防消防、工单、绿色运维、全寿命周期碳 | 运维大屏（6 个子页）、绿色运维、全寿命周期碳 |
| ④ 构件工坊 | 预制柱（套筒灌浆）、叠合梁、叠合板、预制楼梯、预制外墙板：构造拆解 + 安装工艺动画 + 小测 | — |

另有：首页、新手引导（可跳过）、学习中心（任务卡 / 学习进度 / 退场小测）、视角与漫游工具栏、大屏全屏（16:9，可投实验室拼接屏）。手机、平板、电脑都可用，手机建议横屏。

## 本地构建
```bash
npm install
npm run build        # 生成 web/（部署文件夹）和 dist/（离线单文件版）
```
`web/` 是纯静态文件，直接上传到任意网站目录即可，也可双击 `web/index.html` 离线打开。

## 目录
- `src/`：three.js 场景与交互（main.js 主程序、scene.js 沙盘模型、stages.js 阶段、process.js 工序动画、dash.js 数据大屏、workshop.js 构件工坊、teach.js 学习中心、intro.js 新手引导）
- `data/`：数据层（点位、阶段、规范、大屏、场景演示、构件工坊、题库），预留真实数据接口
- `tools/`：构建与截图脚本
- `docs/`：开发说明、点位清单、平面布置图、构件工坊说明、预览图
