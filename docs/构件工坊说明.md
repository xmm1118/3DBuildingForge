# 构件工坊 · 开发说明（2026-11-25）

5 种装配式构件，每种三块：**构造**（拆解模型 + 点选说明）、**安装工艺**（6~7 步动画 + 工序卡）、**小测**（3 题）。
文字全部在 `data/workshop-data.js`，几何与动画在 `src/workshop.js`。

预览：`docs/构件工坊预览.jpg`（1920×1080 联系表：每列一个构件，三行依次为构造拆解 / 工艺中间一步 / 小测），`docs/构件工坊预览-手机横屏.jpg`（844×390）。

## 1. 接口（与主程序约定）

```js
import { mountWorkshop, WORKSHOP_CSS } from './workshop.js';   // three 与 OrbitControls 的引入方式同 main.js
const ws = mountWorkshop(hostEl, { onExit, onQuiz });
ws.open(id)      // 打开某构件；不传 id → 构件目录（5 张卡片，缩略图现场渲染）
ws.close()       // 停止渲染循环
ws.list()        // [{id, name, short}]
ws.resize()      // 按 hostEl 的 clientWidth/clientHeight 重排（不看 window）；内部还挂了 ResizeObserver
ws.dispose()
// onExit()：点「回到工地」；onQuiz({id, correct, total})：小测提交后
```

- CSS 类名全部以 `ws-` 开头；宿主把 `WORKSHOP_CSS` 注入即可。
- 布局按宿主尺寸切换：`ws-narrow`（宽 < 760，侧栏变底部面板）、`ws-short`（高 ≤ 500 且横屏：右侧紧凑工序卡 + 「列表」底部抽屉）。
- 渲染循环只在 open 后运行，close() 停止；小测与目录页不渲染 3D。
- `prefers-reduced-motion: reduce`：工序直接显示每步结束状态，自动播放每 5 秒翻一步，相机不做飞行与阻尼。
- 部件 id：pc-column / comp-beam / comp-slab / pc-stair / pc-wall。

## 2. 数据字段 `window.SHAPAN_WORKSHOP`

```
components[]: {
  id, name, short, desc,
  parts[]: { id, name, fn(作用), req(关键要求), norm(依据) }   // id 与 workshop.js 中 P('id', …) 一一对应
  steps[]: { t(工序名), do(做什么), key(质量/安全要点), norm(规范依据) }  // 顺序与动画一一对应
  norms:  [[规范编号, 条文号串]]                                // 侧栏底部「本构件引用」
}
questions[]: { comp, q, tip, opts[4], ans(0 起), }               // 每构件 3 题，共 15 题；格式同 teach-data 的 {q,tip,opts,ans}
```

改文字只动数据文件；增删部件或工序要同时改 `workshop.js` 里对应的 `buildXxx()`（部件 `P(id, kind, explode向量)`，工序 `steps[i](k, A)`，k 为 0→1 的进度）。
部件 kind：conc 预制混凝土 / adj 相邻结构 / cast 现浇 / steel 钢筋 / embed 预埋件 / temp 临时支撑 / other 其他；「只看钢筋」显示 steel + embed，「混凝土透明」作用于其余类。

## 3. 各构件内容

| 构件 | 构造部件 | 安装工序 |
|---|---|---|
| 预制柱（套筒灌浆） | 柱身(键槽/粗糙面)、纵筋、箍筋加密区、全灌浆套筒、灌浆孔/出浆孔、吊件、下层插筋、柱底接缝与钢垫片、下层结构、可调斜撑（10） | 测量放线与标高 → 插筋校正 → 吊装就位(试吊、300~500mm 对位) → 斜撑与垂直度 → 分仓封缝 → 套筒灌浆(下口灌上口出、试块) → 养护与拆撑（7） |
| 叠合梁 | 预制梁、梁端键槽与粗糙面、开口箍筋、箍筋帽、下部纵筋(锚固板)、上部纵筋、吊件、后浇叠合层与节点、两端柱、独立支撑（10） | 支撑与标高 → 梁边控制线与钢筋复核 → 吊装 → 就位校正 → 穿上部筋扣箍筋帽 → 隐蔽验收后浇筑 → 养护拆撑（7） |
| 叠合板 | 预制底板、粗糙面、钢筋桁架、底板钢筋网、板端外伸筋、吊点、线盒与管线、板面筋、叠合层、支座梁、独立钢支柱与托座（11） | 支撑 → 起吊与空中调整 → 就位与接缝校核 → 管线与板面筋 → 验收浇筑 → 养护拆撑（6） |
| 预制楼梯 | 梯段、板底/板面纵筋、分布筋、销键预留孔、吊件、上端支座(固定铰)、下端支座(滑动铰)、预埋销键、找平层、端缝填充（11） | 定位标高与调平 → 试吊起吊 → 对孔落位 → 校正固定 → 节点：上固定下滑动 → 成品保护（6） |
| 预制外墙板（夹心保温外挂） | 内叶板、保温层、外叶板、拉结件、内/外叶钢筋网、洞口加强筋、点支承节点(下 2 承重 + 上 2 限位)、背衬棒+密封胶、吊件、边梁楼板、相邻墙板（12） | 放线与预埋复核 → 分配梁吊装 → 下部承重节点就位 → 上部限位节点与校正 → 板缝打胶 → 淋水检验 → 节点防护验收（7） |

模型尺寸按真实构件取（米）：柱 600×600×2900、套筒 Φ62×450；梁 300 宽、预制 350 + 叠合 150；板 60 + 70，桁架高 80、间距 500、距边 250；楼梯 9 踏步 167×260、梯板厚 120；外墙板 3.0×2.92，内叶 150 / 保温 70 / 外叶 60，板缝 15。

## 5. 测试

```bash
mkdir -p ~/.fonts; cp /workspace/fonts/NotoSansCJK-*.ttc ~/.fonts; fc-cache
bash tools/ws_build.sh                       # esbuild 打包 src/workshop.js，内联生成 tools/ws_test.html（?id=pc-column 直达某构件）
# 120s 限时环境分段跑，输出先重定向到文件再看
uv run -q --with playwright==1.52.0 --with pillow python tools/ws_shot.py main pc-column comp-beam comp-slab > /tmp/a.log 2>&1
uv run -q --with playwright==1.52.0 --with pillow python tools/ws_shot.py main pc-stair pc-wall > /tmp/b.log 2>&1
uv run -q --with playwright==1.52.0 --with pillow python tools/ws_shot.py steps pc-column comp-beam > /tmp/c.log 2>&1   # 每步截图
uv run -q --with playwright==1.52.0 --with pillow python tools/ws_shot.py misc > /tmp/d.log 2>&1   # 目录、844×390、390×844、1024×768
uv run -q --with playwright==1.52.0 --with pillow python tools/ws_shot.py sheet                      # 生成两张预览图
```

截图放在项目 `work/ws_shots/`（可用环境变量 WS_OUT 改）。结果：页面无 console error / pageerror；日志里仅有 swiftshader 截图回读产生的 4 条「GL Driver Message … GPU stall due to ReadPixels」性能提示，不是程序错误。另测过 reduced-motion、list()、目录卡片跳转、回到工地、close/dispose。

## 6. 已知局限

- 吊装用一个通用吊钩 + 钢丝绳示意，没有画塔吊本身（工地主场景里已有塔吊动画）。
- 板缝 15mm 在整板视角下很细，工序第 5、6 步会自动拉近到板缝。
- 每步切换时相机会飞到该步预设视角；拖动视角会立即中断飞行。
